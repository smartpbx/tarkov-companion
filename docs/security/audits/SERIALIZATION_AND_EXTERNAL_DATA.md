# Serialization and external-data adversarial review

Review lane for #317, recorded 2026-09-14 against `d59d136`. This is a source review only:
no network request, build, product test, debugger, container, or VM was run. Evidence tiers use
`docs/security/METHODOLOGY.md`: **Reviewed** means the cited implementation and existing tests
were read; it is not exploit proof or an exact-head CI result.

## Scope and method

This lane traced current JSON import/export, SQLite migrations, public catalog and optional
TarkovTracker HTTP reads, relay catalog mirroring, map catalog/assets, and the frozen V2 JSON
contract. It also searched production source for archive extractors and CSV importers: there is
no current archive import/extraction surface and CSV is export-only. `docs/V2_CONTRACT.md` is a
target contract; its `V2ContractJson` options are not evidence that every v1 transport uses them.

The phase-1 register already records `RISK-LOCAL-IMPORT-EXPORT-INTEGRITY`,
`RISK-CATALOG-INTEGRITY`, and `RISK-UPDATE-CHANNEL-TRUST`. Rows below do not duplicate their
authenticity, replay, disclosure, or release-channel claims: they add exact availability,
schema, redirect, spreadsheet, and migration evidence discovered in this lane.

## Release conclusion

This lane finds two High availability defects in current catalog/mirror ingestion, plus Medium
profile-schema, CSV, migration, and asset-origin defects. The existing bounded quest and
TarkovTracker readers demonstrate the expected pattern but cannot compensate for the separate
v1 catalog, relay, and profile paths. #317 should remain open until owners accept or implement
the listed release dispositions and exact-head GitHub Actions demonstrates the resulting tests.
