unearned "reviewed" claim `METHODOLOGY.md`'s evidence tiers exist to prevent.

## What this means for #317's closeout, not just phase 1

`docs/security/` as a directory should be treated as a living register that grows one section per
component as each of the above lands, reviewed with the same evidence-tier discipline as this
pass — not re-derived from scratch each time. When a component here gets its first implementation,
the right move is to extend `SYSTEM_AND_TRUST_BOUNDARIES.md` with a new `TB-N`, add its abuse
cases to `ABUSE_CASES.md`, and add its findings to `CONTROLS_AND_RESIDUAL_RISK.md` — not to start a
new document set.
