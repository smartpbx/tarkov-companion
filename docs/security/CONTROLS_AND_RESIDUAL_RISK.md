# Controls and residual-risk register

Evidence tiers are defined in `METHODOLOGY.md`. Every row in this phase-1 register is
**Reviewed**: implementation/configuration was read, but this docs pass did not execute an exploit,
penetration test, or product test. A later exact-head CI result can be cited as automated evidence
for the checks it actually runs; workflow configuration alone is not test evidence.

Every open row has an explicit release disposition. **Mitigate** is required work; **Defer** means
the named later design/review owns it and the row remains open; **Accept** records a bounded
residual risk. No High/Critical row below is silently accepted.
