# Controls and residual-risk register

Evidence tiers are defined in `METHODOLOGY.md`. Every row in this integrated wave-2 register is
**Reviewed**: implementation/configuration and named test source were read, but this docs pass did
not execute an exploit, penetration test, build, or product test. A later exact-head CI result can
be cited as automated evidence only for the checks it actually runs; workflow configuration and an
unobserved test name are not test evidence.

Issue #280 refreshed the two update-channel rows against its current source. They remain
**Reviewed**, not deployed or CI-proven: the private feed and protected environments do not yet
exist, and the desktop consumer's composition/state transaction belongs to #294/#270.

Every open row has an explicit release disposition. **Mitigate** is required work; **Defer** means
the named later design/review owns it and the row remains open; **Accept** records a bounded
residual risk. No High/Critical row below is silently accepted.
