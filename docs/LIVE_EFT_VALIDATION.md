# Live EFT validation

Direct validation against Escape from Tarkov is pending because EFT is not installed in the Windows VM. Do not claim full real-game verification until this checklist is completed on the gaming Windows installation.

## Installation

- [ ] Extract/install the v1 release and launch it normally.
- [ ] Configure or auto-detect EFT logs and screenshots.
- [ ] Select the second monitor.
- [ ] Confirm the scan hotkey does not affect gameplay unexpectedly.

## Menu and stash scanning

- [ ] Scan a known barter item and verify the item/value.
- [ ] Scan a valuable item and check current price plausibility.
- [ ] Scan an ammo box and verify contained ammunition/tier.
- [ ] Scan a key and consumable; verify intelligence/event state.
- [ ] Scan a mixed visible container and assess ambiguity handling.

## Raid, position, and extracts

- [ ] Enter a raid and verify allowed log output selects the correct map/state.
- [ ] Manually take a normal EFT screenshot; verify position, heading, floor, and eventual stale status.
- [ ] Display the extract list and scan; verify recognized active extracts and manual correction.

## Performance and safety

- [ ] Observe no meaningful EFT FPS impact or continuous capture load.
- [ ] Confirm scan latency and full-raid stability are acceptable.
- [ ] Confirm no BattlEye/game warning attributable to the integration.

Record app/game builds, date, resolution, window mode, scaling, monitors, and pass/fail notes. Store screenshots/logs only when Debug Capture is explicitly enabled.
